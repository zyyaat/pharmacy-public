# Pharmacy POS — تطبيق نقطة البيع

تطبيق مستقل خفيف لنقطة البيع، من نفس مستودع ونفس منطق `pharmacy-app` بالحرف:
نفس جلسات الدخول، نفس نظام الصلاحيات المرن (مفاتيح `pos.access` / `sales.view` /
`customers.create` / `customers.payments` / `sales.returns`)، نفس الباك إند Go
ونفس قاعدة البيانات — بلا أي تكرار للمنطق في الخادم.

## الصفحات

| المسار | الوصف | الصلاحية |
|---|---|---|
| `/login` | دخول بنفس حساب الصيدلية | — |
| `/` | تحويل تلقائي إلى نقطة البيع | — |
| `/pos` | شاشة البيع الكاملة: بحث بالباركود/الاسم، السلة، آجل، إضافة عميل سريع، طباعة إيصال، فواتير معلقة | `pos.access` |
| `/sales` | سجل المبيعات | `sales.view` |
| `/sales/[id]` | تفاصيل الفاتورة: إعادة طباعة + استرجاع | `sales.view` + `sales.returns` للزر |

الأزرار والأقسام الممنوعة مخفية كليًا (نفس بوابة `<Can>` / `<RequirePermission>`
والهيكل العظمي بلا وميض كما في التطبيق الرئيسي)، والفرض الحقيقي باقٍ في الباك إند.

## التشغيل المحلي

```bash
npm install
npm run dev -- -p 3001   # الباك إند على 8080 كالمعتاد — البروكسي مدمج
```

## النشر على Vercel (مشروعان من نفس المستودع)

Vercel يستضيف الواجهات فقط؛ باك إند Go + PostgreSQL يبقيان على خادمك (أو
Railway/Fly/Neon). أنشئ **مشروع Vercel لكل تطبيق** بنفس المستودع:

| الإعداد | مشروع الإدارة | مشروع نقطة البيع |
|---|---|---|
| Root Directory | `frontend/apps/pharmacy-app` | `frontend/apps/pos-app` |
| Framework Preset | Next.js | Next.js |
| Build Command | `next build` (افتراضي) | `next build` (افتراضي) |

متغيرات البيئة لكل مشروع:

- `NEXT_PUBLIC_API_URL=/api/v1` — يبقي النداءات same-origin عبر بروكسي rewrites
  المدمج في `next.config.js` فلا CORS ولا مشاكل كوكيز بين الدومينين.
- `BACKEND_INTERNAL_URL=https://api.<نطاقك>` — عنوان الباك إند الذي يصبّ عليه
  البروكسي داخل Vercel (نفس القيمة للمشروعين).

بعد النشر اربط الدومينات من لوحة Vercel: `app.<نطاقك>` لمشروع الإدارة و
`pos.<نطاقك>` لمشروع نقطة البيع.

## ملاحظة صيانة

ملفات البنية المشتركة (`lib/api.ts`، `lib/permissions.ts`، بوابات
`components/permissions`، مكونات `components/ui`، خطافات `hooks/`) منسوخة
حاليًا بنسخة مطابقة من `pharmacy-app` (نفس نمط التطبيقات في هذا المستودع).
عند أي تعديل جوهري عليها في أحد التطبيقين يُراجع الآخر — ويظل المنطق
الأمني الفعلي مفروضًا من الباك إند على كل الأحوال.
